# Matchin v48 — численные константы и единое раскрытие

Основа: пользовательский `Matchin-v47.4-range-verdict.html`. Сборка добавляет коэффициентные выражения физических констант и единый рекурсивный интерпретатор приставок, констант и физических формул. Просмотра структуры в пользовательском интерфейсе нет.

Откройте `Matchin-v48-registry-expansion.html` в современном браузере. Нужен доступ к GitHub для загрузки JSON из `Cube3-C3/Packages`: сначала выбирается одна ревизия ветки, затем все десять файлов читаются из неё. Резервная фиксированная ревизия данных: `ab4aa4ce2765e3a6a145ba9665ef21b3c899e4ef`. Параметр `?ref=<SHA>` позволяет выбрать фиксированную совместимую ревизию.

- `23 см` раскрывается как `23·10⁻² м`; `23 см²` — как `23·(10⁻²)² м²`; `(23 см)²` — как `(23·10⁻²)² м²`. Значения в СИ: `0,23`, `0,0023`, `0,0529` соответственно.
- Выберите квантовую механику либо значение «постоянная Планка» для `h` в `E=hν`. Проекция раскрывает `h` как `6,62607015·10⁻³⁴` с сохранением размерности `кг·м²·с⁻¹`. Исходный текст и его токены сохраняются.
- Доступны коэффициенты всех восьми зарегистрированных физических констант. Для `ℏ` действует выражение `h/(2π)`. Число `π` сохраняется символически.
- Экспериментальные `G`, `ε₀`, `μ₀` показываются со знаком приближения, изданием источника и стандартной неопределённостью. Они не подставляются как точные числа при доказательстве равенства. Для `ε₀` и `μ₀` сохранены значения CODATA 2018 из исходного реестра.
- `R = 8,31446261815324` используется без прежнего усечения.

Разработчику доступны `Matchin.expansion.expand`, `.constant`, `.coefficient`, `.law`, `.validate`. Результат раскрытия содержит `tree`, `expansions`, `exact`, `work`. Пример численного коэффициента: `Matchin.expansion.constant('C002', {representation:'blocks'})`. Коэффициент закона: `Matchin.expansion.coefficient('P007', {representation:'blocks'})` возвращает `1/2`. Это коэффициентное выражение; физическая размерность сохраняется при раскрытии выбранного физического употребления через `.expand`.

У `.expand` есть параметры `physicsSession`, `rows`, `measurements`, `representation`, `exactOnly`, `bindings`, `coefficientOnly`, `maxWork`. По умолчанию используются только точные константы. Для показа справочного приближённого значения задаётся `exactOnly:false`. Параметры коэффициентов связываются структурными JSON-выражениями: `bindings:{k:['integer','3']}`. Строки исходного ввода и строковые подписи коэффициентов не разбираются.

Интерпретатор не записывает производные символы в EDIT. У каждого производного символа собственный ID и владелец, `origin:'DERIVED'`, `sourceIds`. В `см²` числовой множитель ссылается на символ приставки `с`, единица — на `м`, обе копии показателя — на исходный `²`.

Проверки: установите Python-пакет `playwright` и Chromium, затем из корня репозитория запустите:

```sh
python Matchin/tests/verify.py
```
