# Matchin — отчёт о фактическом покрытии сборки

**Артефакт / версия:** `Matchin-v48-registry-expansion.html`, 48-registry-expansion.

**Эталон спецификации:** вложенный `Matchin-v47.4-range-verdict.html` и запрос пользователя от 03.11.2026 о распределении символов в `23 см`/`23 см²`, коэффициентных значениях физических констант и едином рекурсивном раскрытии. Дополнение пользователя: просмотра структуры в интерфейсе не нужно. Отдельная нормативная спецификация EDIT не предоставлена; полное соответствие всему концепту не оценивалось.

**Статус:** полный кандидат в пределах указанного задания, не заявление о полной реализации всего Matchin.

**Область, согласованная до работы:** коэффициентные выражения всех восьми зарегистрированных физических констант; единое раскрытие приставок, констант и коэффициентов законов; сохранение размерности, исходных токенов и области действия степеней; браузерные сценарии и проверка регрессионных примеров. Область объявлена в чате до изменения кода. Просмотр структуры удалён по уточнению пользователя.

Реестры: `physi_quant` 0.14, `usages` 0.4, `physi_coefficients` 1.1.0. Основа данных — публичная ревизия `c1fe85835200ec9ff4cbe01fb482a6d680fa8710`, обновлённая ревизия — `ab4aa4ce2765e3a6a145ba9665ef21b3c899e4ef`.

## 1. Реализовано и проверено

| Требование / возможность | Где реализовано | Свидетельство проверки |
|---|---|---|
| Коэффициентные выражения C001–C008 | `physi_quant.json`, `buildCatalogue`, `coefficient_value` в употреблениях | 8 отдельных сценариев точного сравнения сохранённых цифр и проверки 8 записей/всех их употреблений |
| Полное точное значение R | C004: `8.31446261815324` | Сравнение с полным и прежним усечённым значениями |
| h и ℏ имеют разные коэффициенты | Переопределение `coefficient_value` для `reduced_planck` в `usages.json` | `ℏ = h/(2π)`; проверка неравенства h и ℏ |
| Один математический путь раскрытия | `module_registry_expansion`: единый `visit`; адаптеры данных поставляют выражения | Совместное раскрытие h и см², вложенные ссылки P007 → P213; 67 правых частей и 72 коэффициентные записи |
| 15 структурных коэффициентных выражений для 72 формул | `physi_coefficients.json`, `coefficientIndex.expressions` | Все 72 ссылки раскрываются; точные 1/2, 2/3, −1; связывание k; символические π и sin |

| Разделение происхождения приставки, единицы и показателя | `sourceIds`, `origin:DERIVED`, собственные ID/owner | Проверка источников с/м/², отсутствия повторных ID и единственности владельца |
| Нет записи проекции в EDIT | `units.expand` делегирует отделённому интерпретатору | Снимки токенов, дерева, курсора, журнала и истории совпадают до/после; undo/redo сохраняют область степени |

| Приближённые значения отделены от точных доказательств | `exactOnly`, признаки точности, стандартные неопределённости | G не принимается за точное число; UI показывает ≈ и неопределённость |
| Выбор смысла символа управляет раскрытием | Штатная физическая сессия и существующая проекция СИ | h как переменная не раскрывается; изменение select обновляет проекцию сразу |
| Нет пользовательского просмотра структуры | В UI только численная проекция и источник | Проверка отсутствия элемента просмотра структуры; скриншоты широкого и узкого экрана |

## 3. Не реализовано

| Требование / возможность | Следствие для пользователя |
|---|---|
| Универсальное решение любых физических уравнений и нелинейных связанных ОДЗ | Существующие ограничения решателя сохраняются; новые тесты не подтверждают универсальность |
| Новое десятичное приближение математических констант | π в коэффициентах и h/(2π) сохраняется символически; исходные математические константы не объявлены точными десятичными числами |
| Новые единицы вне исходного реестра | Например, `ч` отсутствует в исходном units.json и не превращается автоматически в 3600 секунд |

Пропущенных функций текущего запроса не выявлено. Перечисленное выше не входило в заявленную область изменения.

## 4. Намеренные ограничения прототипа

- Сокращений текущего запроса нет. Нормативное покрытие всего Matchin не заявлялось до реализации и не заявляется после неё.
- Новые типы EDIT не добавлялись. Раскрытие использует существующие `number`, `integer`, `fractional`, `unod`, `binod`, `variable`, `function`, `quantity`, `dimension`, `dimension_unit` и списки аргументов. Число покрытых типов относительно полной нормативной спецификации неизвестно: её нет во входных данных.
- События INSERT/REPLACE/FOCUS/CHOOSE/UNDO/REDO не заменены новым входным маршрутом. Проверены ввод, выход из имени, незавершённая степень, выбор физического смысла, undo/redo; исчерпывающая проверка всех событий не выполнялась.
- В данных восемь физических констант; все восемь получили коэффициентные выражения. Новые физические константы и новые единицы не добавлялись. Для ε₀ и μ₀ сохранены значения CODATA 2018 исходного реестра, а не заявлено обновление всех экспериментальных данных до последнего издания.
- По умолчанию численная подстановка для доказательств допускает точные записи. Экспериментальные данные доступны в проекции с явным признаком приближения. Распространение метрологической неопределённости через произвольные вычисления не реализовывалось и не входит в запрос.
- Адаптация декларативных схем законов строит структурные шаблоны; математическое раскрытие выполняет один интерпретатор. Подписи коэффициентов не разбираются при выполнении, скрытого парсера восстановления ввода не добавлено.
- Просмотр структуры в приложении отсутствует согласно уточнению пользователя; дерево доступно существующему инструменту разработчика через API.

## 6. Итог и следующий проверяемый шаг

- Подтверждены все возможности текущего запроса в описанной области: коэффициентные значения C001–C008, единое рекурсивное раскрытие, правильная область степеней, источник каждого производного символа, сохранение размерности и исходного ввода, отсутствие просмотра структуры в UI.
- Полное нормативное соответствие концепту Matchin, все исторические ветви EDIT, все физические контексты и все браузеры не подтверждены.
- Известных дефектов изменённой логики в выполненных сценариях не выявлено. Существующие ограничения и границы перечислены в разделах 2–4.
- Следующий проверяемый шаг: загрузить опубликованный HTML и реестры из фиксированной GitHub-ревизии и повторить `23 см²`, `E=hν` и отказ для неверного коэффициента. Результат этой проверки фиксируется отдельно, чтобы не смешивать локальный стенд и сетевую проверку.
